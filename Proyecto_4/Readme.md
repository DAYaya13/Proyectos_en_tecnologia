# 🧠 Reporte de Accidentabilidad – Power BI

## 📋 Descripción del Proyecto

Este proyecto presenta un **Dashboard interactivo en Power BI** diseñado para el **análisis mensual de accidentabilidad laboral**.  
El objetivo principal es **monitorear indicadores clave de seguridad industrial (SST)**, detectar patrones en los accidentes y facilitar la **toma de decisiones basada en datos**.

El reporte permite visualizar de manera clara y dinámica los principales **indicadores de desempeño HSE (Health, Safety & Environment)** relacionados con accidentes, turnos y áreas operativas.

---

## 📊 Contenido del Dashboard

### 🔹 Indicadores Principales (KPIs)
- Total de **accidentes registrados**
- Total de **días perdidos**
- Total de **horas-hombre trabajadas**
- **Tasa de Incidencia (TIR)**

### 📈 Gráficos y Visualizaciones
- **Accidentes y días perdidos por mes** → columnas apiladas + línea de tendencia  
- **Accidentes por área** → barras apiladas  
- **Accidentes por turno** → barras agrupadas  
- **Accidentes por clasificación** → leve, incapacitante, parcial permanente  
- **Accidentes por sexo o género** → gráfico de anillos  

Cada visual está conectada a **filtros interactivos**, permitiendo analizar tendencias mensuales, por área o tipo de accidente.

---

## 🎯 Objetivo Analítico

El Dashboard busca:
- Detectar **tendencias en la accidentabilidad** por área o turno.  
- Identificar **segmentos con mayor riesgo operativo**.  
- Apoyar la **planificación de medidas preventivas**.  
- Proveer información consolidada para **reportes mensuales corporativos**.

---

## 🧩 Herramientas Utilizadas

| Herramienta | Uso |
|--------------|-----|
| **Power BI** | Creación de dashboard, modelado y visualización de datos |
| **Excel / CSV** | Fuente de datos (registro de accidentes y horas hombre) |
| **DAX** | Cálculos de TIR, KPIs y medidas dinámicas |
| **Power Query** | Limpieza y transformación de datos |

---

## 🧮 Indicadores Técnicos

- **Tasa de Incidencia (TIR)** = (Número de Accidentes × 200,000) / Horas Hombre  
- **Índice de Frecuencia (IF)** y **Días Perdidos** pueden integrarse en futuras versiones.

---

## 🚀 Resultados y Conclusiones

El análisis permitió identificar:
- Áreas con **mayor recurrencia de accidentes leves e incapacitantes**.  
- Turnos con **mayor carga de riesgo operativo**.  
- Diferencias de comportamiento entre **géneros**.  
- Una **tendencia general de disminución de accidentes** en los meses más recientes.

📈 Este reporte puede escalarse para incluir:
- Datos históricos anuales  
- Clasificación por **causa raíz**  
- Integración con indicadores ambientales (**HSE**)
